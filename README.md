# Wortschatz

Version web de Wortschatz, application de suivi des interrogations de vocabulaire allemand.

- [Ouvrir Wortschatz](https://sbtchr.github.io/Wortschatz/)
- [Essayer avec des élèves fictifs](https://sbtchr.github.io/Wortschatz/?demo=1)

Le navigateur enregistre les données de travail dans un espace local chiffré. Les fichiers JSON peuvent être importés et exportés depuis Réglages. Les commentaires sont générés sur l’appareil.

Ce dépôt contient les fichiers générés de l’application web et son déploiement GitHub Pages. La clé d’accès à un espace personnel reste sur l’appareil de l’utilisateur.
